# Frontend

这是 Workflow Jobs 项目的前端部分，使用 Vite + React + TypeScript 构建。

## 开发

```bash
# 从项目根目录运行
pnpm dev:frontend
```

或者进入 frontend 目录：

```bash
cd frontend
pnpm vite
```

## 构建

```bash
# 从项目根目录运行
pnpm build:frontend
```

构建产物会输出到 `dist-frontend` 目录。

## 预览构建结果

```bash
pnpm preview:frontend
```
